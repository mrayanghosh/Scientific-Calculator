# Scientific Calculator

A modern, responsive, and fully functional scientific calculator built with **HTML**, **CSS**, and **JavaScript**.

## Features
- Standard and scientific functions (sin, cos, tan, log, factorial, etc.)
- Memory operations (M+, M-, MR, MC)
- Calculation history panel
- Responsive design for mobile screens
- DEG/RAD mode toggle

## Usage
Open [https://mrayanghosh.github.io/Scientific-Calculator/](https://mrayanghosh.github.io/Scientific-Calculator/) to use the calculator.

## Google Search (SEO)
This project includes:
- JSON-LD structured data for Google rich results
- Open Graph & Twitter Card meta tags
- Canonical URL pointing to your GitHub Pages

To enable Google Search indexing:
1. Deploy this project to GitHub Pages under the repo `Scientific-Calculator`
2. Go to [Google Search Console](https://search.google.com/search-console/)
3. Add your site: `https://mrayanghosh.github.io/Scientific-Calculator/`
4. Verify ownership (Google will give you a `<meta>` tag — paste it in `index.html` where indicated)
5. Submit your sitemap or request indexing
